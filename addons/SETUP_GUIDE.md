# HHBrowser Add-on System - Complete Setup Guide

This guide explains how the add-on system works and how to fix common issues.

## System Overview

### How Add-ons Are Discovered

1. HHBrowser starts and initializes the `AddonManager`
2. Manager looks in the `addons/` directory
3. For each **folder** found, it looks for `manifest.json`
4. If `manifest.json` exists and is valid, the folder is a valid addon
5. The addon info is read from the manifest
6. If enabled in `addons.json`, the addon is loaded

### Key Files

- **manifest.json**: Metadata about the addon (read-only for system)
  - Name, version, description, author
  - Which file contains the addon class ("main" field)
  - Default enabled/disabled state

- **addons.json**: State tracking (managed by system)
  - Which addons are currently enabled/disabled
  - User settings per addon
  - Auto-generated on first run

## Understanding the Manifest

Every addon MUST have a `manifest.json` in its root folder:

```json
{
  "name": "Display Name",          // Required: what users see
  "version": "1.0.0",               // Required: semantic version
  "description": "What it does",    // Required: brief description
  "author": "Your Name",            // Required: author name
  "main": "addon.py",               // Required: entry point file
  "enabled": true,                  // Optional: default enabled state
  "license": "MIT",                 // Optional: license type
  "keywords": ["tag1", "tag2"]      // Optional: search keywords
}
```

### Manifest Field Reference

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| name | string | YES | Display name in UI |
| version | string | YES | Use semantic versioning: 1.0.0 |
| description | string | YES | One-line description of addon |
| author | string | YES | Addon author name |
| main | string | YES | Python file with addon class (e.g., "addon.py") |
| enabled | boolean | NO | Default: true. Override in addons.json |
| license | string | NO | License type (MIT, GPL, etc.) |
| keywords | array | NO | Tags for searching |
| settings | object | NO | Default settings object |

## Why Addons Don't Show Up

### Problem: Addon folder not discovered

**Symptom**: You created `addons/my_addon/` but it doesn't appear in Manage Add-ons

**Checklist**:
```
✓ Folder exists: addons/my_addon/
✓ manifest.json exists in folder
✓ manifest.json is valid JSON
✓ manifest.json has required fields
  ✓ name
  ✓ version
  ✓ description
  ✓ author
  ✓ main
```

**Test manifest validity**:
```bash
python -m json.tool addons/my_addon/manifest.json
```

Should output formatted JSON, not an error.

### Problem: Addon shows but won't enable

**Symptom**: Addon appears in list but clicking "Enable" does nothing or errors

**Checklist**:
```
✓ Main file exists: addons/my_addon/addon.py
✓ Main file contains class inheriting from HBrowserAddon
✓ Class has init(browser_instance) -> bool method
✓ Class has unload() -> bool method
✓ init() returns True (not None, not False)
✓ No syntax errors in Python file
```

**Check console** for error messages when trying to enable.

**Test Python syntax**:
```bash
python -m py_compile addons/my_addon/addon.py
```

Should not output anything if syntax is valid.

### Problem: Addon enabled but features don't work

**Symptom**: Addon shows as enabled but hooks aren't firing, menu items don't appear

**Checklist**:
```
✓ init() method executed without errors
✓ self.browser_instance is set
✓ Hook method names are spelled correctly
✓ Hook method signatures match expected parameters
✓ get_menu_actions() returns list of dicts with keys: "menu", "label", "callback"
✓ No exceptions in hook methods (wrap in try-except)
```

**Add debug prints**:
```python
def on_page_loaded(self, url: str, title: str) -> None:
    print(f"DEBUG: on_page_loaded called with {title}")
    # Your code here
```

Check console output when triggering the hook.

## Common Mistakes

### 1. No manifest.json
```
❌ addons/my_addon/addon.py        # Won't be discovered!
✅ addons/my_addon/manifest.json   # Create this
✅ addons/my_addon/addon.py        # Now works
```

### 2. Wrong main entry point
```json
❌ "main": "__init__.py"           // Don't use __init__.py
✅ "main": "addon.py"              // Use this instead
```

### 3. init() doesn't return True
```python
❌ def init(self, browser_instance):        # Returns None
     self.browser_instance = browser_instance

✅ def init(self, browser_instance) -> bool:  # Returns True
     self.browser_instance = browser_instance
     return True
```

### 4. Manifest JSON is invalid
```json
❌ {
     "name": "My Addon"
     "version": "1.0.0"    // Missing comma!
   }

✅ {
     "name": "My Addon",
     "version": "1.0.0"
   }
```

### 5. Wrong menu name
```python
❌ "menu": "MyCustomMenu"           // This menu doesn't exist

✅ "menu": "Tools"                  // Use existing menus
✅ "menu": "File"
✅ "menu": "View"
```

### 6. Missing import
```python
❌ class MyAddon(HBrowserAddon):    # HBrowserAddon not imported!
     pass

✅ from addon_system import HBrowserAddon
   class MyAddon(HBrowserAddon):
     pass
```

## How to Test Your Addon

1. **Create folder structure**:
   ```bash
   mkdir addons/test_addon
   ```

2. **Create manifest.json**:
   ```json
   {
     "name": "Test Addon",
     "version": "1.0.0",
     "description": "Testing",
     "author": "Test",
     "main": "addon.py",
     "enabled": true
   }
   ```

3. **Create addon.py** with test code:
   ```python
   from addon_system import HBrowserAddon
   
   class TestAddon(HBrowserAddon):
       def init(self, browser_instance) -> bool:
           print("✓ Test addon loaded!")
           self.browser_instance = browser_instance
           return True
       
       def unload(self) -> bool:
           print("✓ Test addon unloaded")
           return True
   ```

4. **Reload addons** in HHBrowser:
   - Go to `Tools > Add-ons > Reload Add-ons`
   - Check console for "✓ Test addon loaded!"

5. **Enable addon**:
   - Go to `Tools > Add-ons > Manage Add-ons`
   - Select "Test Addon"
   - Click "Enable Selected"
   - Should see confirmation in console

6. **Test hooks**:
   ```python
   def on_page_loaded(self, url: str, title: str) -> None:
       print(f"✓ Page loaded: {title}")
   ```
   - Load a webpage
   - Should see message in console

## Debugging Tips

### Enable Console Output
Run HHBrowser from terminal to see print() statements:
```bash
python HHBrowser.py
```

### Add Debug Prints
```python
print(f"DEBUG: Variable = {variable}")
print(f"DEBUG: Type = {type(value)}")
print(f"DEBUG: List contents = {list_var}")
```

```bash
python -c "import json; json.load(open('addons/my_addon/manifest.json'))"
```

### Check File Permissions
```bash
ls -la addons/my_addon/
# All files should be readable
```

### Test Python Syntax
```bash
python -m py_compile addons/my_addon/addon.py
```

## Reference

### AddonManager Methods (for system use only)
```python
load_addon(addon_name: str) -> bool      # Load single addon
unload_addon(addon_name: str) -> bool    # Unload single addon
load_all_addons(browser) -> dict         # Load all enabled addons
get_addon(addon_name: str)               # Get loaded addon instance
trigger_hook(hook_name: str, *args)      # Call hook in all addons
```

### HBrowserAddon Methods (for addon developers)

**Required**:
```python
def init(self, browser_instance) -> bool
def unload(self) -> bool
```

**Optional Hooks**:
```python
def on_tab_created(self, tab_index: int, browser_widget)
def on_tab_closed(self, tab_index: int)
def on_url_changed(self, url: str)
def on_page_loaded(self, url: str, title: str)
def on_download_started(self, filename: str, path: str)
```

**Optional UI**:
```python
def get_menu_actions(self) -> List[Dict]
def get_toolbar_actions(self) -> List[Dict]
def get_context_menu_actions(self) -> List[Dict]
```
