# Addon Template - Copy and Customize This

To create a new addon:

1. Copy this entire folder: `cp -r template/ addons/my_addon`
2. Edit `manifest.json` with your addon details
3. Edit `addon.py` with your addon code
4. Reload addons: `Tools > Add-ons > Reload Add-ons`
5. Enable addon: `Tools > Add-ons > Manage Add-ons`

See README.md and SETUP_GUIDE.md for detailed help.
